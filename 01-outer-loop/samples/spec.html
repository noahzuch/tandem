Spec: Offline sync for field notes

Field technicians lose connectivity on site. Notes taken offline must sync without data loss once the device is back online.

Decision needed: last-writer-wins vs. CRDT merge for concurrent edits of the same note.

Goals

  • Never lose a note written offline.
  • Sync completes within 10 s of reconnecting for a typical day of notes.
  • Conflicts are visible to the user, never silently dropped.

Flow

Options

Last writer wins

Simple, but the earlier edit is lost unless we keep revisions.

CRDT merge

No loss, more complex storage, larger payloads.

API sketch

POST /notes/sync
{ "since": 1712, "changes": [ { "id": "n1", "rev": 4, "body": "…" } ] }
