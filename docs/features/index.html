tandem — features

The spike results split into features. Each page will grow into a full business + technical specification.

  • F00 · Project setupThe decisions that are expensive to change later: stack, tooling, repo layout, CI and the Claude plugin skeleton.
  • F01 · Session loopSkill ↔ server ↔ browser ↔ agent: opening a document and getting browser events back to Claude.
  • F02 · Document storage & round tripHTML stays the file on disk; the live Y.Doc is written back without losing anything.
  • F03 · Content model: islands & generic nodesShow any HTML the agent writes, keep it editable where it's text, protect its structure.
  • F04 · Editor UIA WYSIWYG spec editor on Vue 3 + Tiptap (MIT only).
  • F05 · Live collaborationUser and agent edit the same document at the same time without losing characters.
  • F06 · Agent editing & merge engineHow Claude reads and edits the live document without disturbing the user.
  • F07 · Agent change reviewSee what Claude changed, mark it read, reject or undo it.
  • F08 · CommentsThreads on text, blocks, diagrams or the whole document — sent to Claude, answered in place.
  • F09 · Page shell & sidebar panelsThe configurable page around the editor — e.g. the brainstorming journal next to the spec.
  • F10 · Agent skill & guard railsWhat Claude is told, and what stops it from going around the tool.
  • F11 · Security & sanitisingUntrusted HTML and a local server that feeds prompts to the agent.
  • F12 · PublishingMaking the project release-ready: releases, distribution, upkeep and the public face.
Not a feature of its own: the product name (“tandem” is a working name, see N24) — F00 and F12 depend on it. Spike results: SUMMARY.html.
