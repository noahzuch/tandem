F09 · Page shell & sidebar panels specification pending

The configurable page around the editor — e.g. the brainstorming journal next to the spec.

Overview

A server-owned config (.collab/<doc>.shell.json) lists panels per side: outline, comments, activity, file (markdown / journal / html / text), iframe, links. Panels update live from folder watches; layout (size, collapsed, active tab) is per viewer. The journal panel parses the brainstorm skill's decisions.md, and journal ids in the spec become clickable references.

What the spikes settled

  • Config is shared and live, layout is personal; CLI collab panel add|set|remove|open, collab layout (09).
  • Watch folders, not files — survives tools that replace files (09).
  • Journal entry visible in 63–78 ms; real journals (≤202 entries) parse in ≤2.1 ms (09).
  • HTML panels sandboxed without scripts; Markdown with raw HTML escaped (09).

Open / to decide

  • Where the shell config lives: local in .collab/ or checked in with the doc (decisions).
  • Brainstorm skill changes: ids for rejected approaches, machine-readable status token (decisions).
  • References inside diagrams; file panel paths unrestricted; narrow layout (09).
