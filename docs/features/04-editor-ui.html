F04 · Editor UI specification pending

A WYSIWYG spec editor on Vue 3 + Tiptap (MIT only).

Overview

The editing surface: a grouped fixed toolbar, context bubbles (text selection, table), slash menu, block handle and menu, link popover, shortcut sheet, outline, code highlighting and the extension set a spec needs. Everything is generated from one command registry so labels, shortcuts and agent actions can't drift apart.

What the spikes settled

  • Your must-haves: toolbar, context-only bubbles, shortcut sheet and shortcuts on buttons — built; formatting at a bare caret only partly (05).
  • One command registry (src/editor/commands.ts) drives toolbar, bubbles, slash menu, block menu and shortcut sheet (05).
  • Link editor as own popover on @floating-ui/dom, the library Tiptap's bubble uses internally (05).
  • Own outline instead of the TOC extension (it wrote data-toc-id); Link configured without target/rel (04, 05).
  • No paid Tiptap extensions needed (05 · Free vs. paid).

Open / to decide

  • Table controls as row/column handles instead of a bubble; Tiptap's table features may be too limited (N5, 02).
  • Checkboxes as elements inside normal list items instead of TaskList (N9).
  • Formatting menu at the caret without selection; colour picker; narrow/mobile layouts; nested drag (05, open items).
