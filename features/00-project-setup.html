F00 · Project setup specification pending

The decisions that are expensive to change later: stack, tooling, repo layout, CI and the Claude plugin skeleton.

Overview

Sets up the repository every other feature is built in. Only covers choices that shape code from the first commit or are costly to migrate: languages and runtime, frameworks and core libraries, repo/package layout, linting, formatting, type checking, test layers, CI on GitHub and the Claude Code plugin skeleton. Everything that only matters for a public release (dependency automation, README, changelog, publishing) is in F12 · Publishing.

Already fixed by you or the spikes

  • Vue 3 + @tiptap/vue-3, Vite, TypeScript (CONTEXT.md).
  • Open source only: MIT Tiptap packages, Yjs, self-hosted Hocuspocus — no Tiptap Cloud/Pro (CONTEXT.md, 05 · Free vs. paid).
  • Playwright (headless Chromium) for verification (CONTEXT.md).
  • Separate repo and plugin, not part of nessy (decisions · Packaging) — this repo.
  • Claude Code only for now (N2); the CLI ships as a plain binary in the plugin's bin/ (08).
