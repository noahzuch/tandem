F07 · Agent change review specification pending

See what Claude changed, mark it read, reject or undo it.

Overview

Makes agent edits visible and reviewable after they're applied: persistent marks on changed ranges that stay until the user checks them as read, a gutter showing unread changes and comments, an “N agent changes” stepper, per-change reject and an explicit “undo agent change” separate from ⌘Z. Also covers proposals (suggestion mode) for edits that shouldn't be applied directly.

What the spikes settled

  • A short version exists: changed blocks flash in the agent's colour and fade after 2.5 s, matched by block id (07).
  • Proposal mode exists: patch --propose creates a thread with Accept/Reject — but accepted changes aren't on the user's ⌘Z (08).

Open / to decide

  • Persistent marks as a reading list; where stored (Y.Map like comments?), block vs. text-range granularity (N1).
  • Gutter combining unread agent changes and comments; coexistence with drag handle and margin (N15).
  • Second undo manager for agent edits; every revert sends the agent an event (N13).
  • Default edit mode: direct with highlight vs. proposals (decisions). Needs precise ranges from the character diff (N10).
