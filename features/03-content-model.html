Features / F03

F03 · Content model: islands & generic nodes specification pending

Show any HTML the agent writes, keep it editable where it's text, protect its structure.

Overview

Defines how arbitrary HTML maps onto editor nodes. A fixed list of elements become raw-HTML islands (SVG, MathML, canvas, embeds, forms/controls, scripts/styles, comments, captioned tables) shown as-is in a shadow root with editable text; everything else becomes a free generic node protected like a table cell (no collapse, no accidental merge/lift/split, explicit delete with a preview). Also covers attribute/class/style preservation on known nodes.

What the spikes settled

  • Islands only for the fixed list; everything else a generic node — no per-element policy, no data-edit attribute (10, N21).
  • The table-style protection set fixes the four measured free-node problems (Delete pulls next block in, Enter duplicates incl. id, /h2 lifts out, outside selection deletes wrapper) without rejecting transactions (10).
  • Redesigned delete preview; fewer <p> wrappings than with islands (10).
  • PreserveAttributes keeps every class/style/attribute; the document's own <style> is applied, scoped to the editor (04).

Open / to decide

  • Remove the island soft lock: per-label Yjs values or a server-side 3-way text merge of island source (N20).
  • Which content is allowed where — e.g. /table inside a positioned node is allowed and odd (10).
  • Fixed vs. free styles for standard blocks; no style picker today (N3).
