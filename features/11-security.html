Untrusted HTML and a local server that feeds prompts to the agent.

Overview

The server accepts events that become prompt input for the agent and renders HTML the agent (or anyone) wrote. Covers endpoint protection (Host allow-list, Origin checks, a secret token), sanitising islands and panels for display, and restricting what file panels may read.

What the spikes settled

  • Listens on 127.0.0.1 only; no auth on any endpoint (01, 06, 07, 08).
  • Islands are display-sanitised (event handlers and javascript: URLs removed, iframes sandboxed, scripts never run); storage stays verbatim (04).
  • Lavish blocks malicious websites (Host + Origin checks) but not local processes; the spikes block neither (01).

Open / to decide

  • Real sanitiser (DOMPurify in a structure-keeping mode) or islands in sandboxed iframes; shadow root isolates CSS, not JS (N7).
  • Browser WebSocket accepts any page — a visited website could likely send fake feedback (01, read from code, untested).
  • File panels can show any readable file (09). Auth tokens — not verified.
